# AI象棋对弈助手知识库

## 项目范围

AI象棋对弈助手当前版本是 Python + PySide6 的本地练习程序。它提供 10×9 棋盘、基础走子、棋子所属方和红黑方回合状态，界面状态标记为“本地练习模式”。

当前版本尚未接入真实象棋引擎，也没有实现将军、将死、重复局面和完整终局判断。因此，知识问答不能把当前版本描述为已经可以进行真实 AI 对弈。

## 兵卒移动规则

红兵未过河时只能向前移动一格；过河后可以向前移动一格，也可以向左右横向移动一格。黑卒的方向与红兵相反。程序会根据当前回合和棋子所属方拒绝移动对方棋子。

## 棋局保存

程序将棋局保存为本地 JSON 文件 data/games.json。保存内容包括 board 棋盘矩阵、sides 棋子所属方矩阵、current_turn 当前回合、moves 走棋记录和 saved_at 保存时间。读取文件不存在时，程序提示暂无历史对局；JSON 损坏或棋盘尺寸错误时，程序提示读取失败并保留当前棋盘。

## RAG流程与限制

RAG 的最小链路是：问题输入、关键词检索、按相关性排序、把片段和来源编号加入上下文、调用模型、返回带来源的回答。当前实验使用关键词匹配作为可解释的基线，Top-k 默认取3；没有匹配片段时必须返回资料不足，不应编造引用。
