## 执行方式

在项目根目录的 PyCharm 终端执行：

```powershell
.\.venv\Scripts\python.exe -m pytest tests\test_exp4_basics.py -v --tb=short
```

测试使用独立的临时棋局文件，不覆盖用户的 `data/games.json`。测试窗口采用 offscreen 模式，因此执行时不弹出可视窗口；人工运行截图与自动化测试结果共同组成证据。

## 修订版复测结果

- 测试日期：2026-10-12
- 被测代码：实验4修订版提交，初版基准 Commit 为 `2a789a6`
- 结果：12个用例全部通过，0个失败。
- 实际控制台截图：`docs/evidence/exp4/v2-12-test-results.png`
- 同组用例从初版的8通过、4失败变为修订版的12通过、0失败。

修订版同时把界面状态从“本地引擎就绪”改为“本地练习模式”，避免把尚未接入的引擎显示成已就绪。象棋规则目前覆盖基础棋子移动和棋子归属，但尚未检测将军、将死及完整终局条件；产品界面和实验报告应如实说明该限制。

坐标采用(row,col)，从0开始；黑方在棋盘上方，红方在下方。

## 本阶段限制

初版仅有基本点击移动、单份JSON保存与读取，尚未实现完整象棋规则、真实引擎接入和AI评价复盘。界面中的“本地引擎就绪”与实际状态不符，修订时需要更正。自动化测试显示业务缺陷，不能据此将初版写成完整对弈软件。

初版和修订版测试输出均由本机实际运行生成。测试使用独立的临时棋局文件，不覆盖 `data/games.json`。`exp4-v1` Tag 保持指向初版 Commit `2a789a6`，修订版使用 `exp4-v2` Tag。
